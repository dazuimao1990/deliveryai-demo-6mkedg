为沸点火锅点单 Demo 应用新增黑夜模式主题切换能力，提升夜间及弱光环境下的视觉体验

1. 背景与目标

1.1 背景

沸点火锅点单 Demo 当前为单一浅色主题，使用 rice/charcoal/chili/amber 色系硬编码在 JSX 中，Tailwind 未配置 darkMode，无 dark: 变体。

餐饮场景中晚间用餐高峰时段顾客在弱光环境下使用点单界面，浅色背景高亮度屏幕对眼睛刺激明显。设计系统已提供完整的暗色 token 方案（tokens.dark.json），可直接作为黑夜模式色彩基准。

应用已有「老人模式」作为主题切换先例（useElderlyMode hook），黑夜模式可采用相同架构。

1.2 目标

目标衡量方式目标值 / 判断标准
提供黑夜模式切换入口顶栏存在可见的切换按钮用户可在任意视图顶栏找到黑夜模式切换按钮
全视图深色适配视觉检查所有视图5 个视图及所有弹窗在暗色下无浅色残留
偏好持久化刷新页面后保持主题用户切换后刷新，主题保持不变
平滑过渡切换时的视觉体验250ms 平滑过渡，无闪烁

1.3 不做什么

  • 不做跟随系统偏好（prefers-color-scheme）的自动模式
  • 不做主题定制市场或自定义颜色选择
  • 不修改 server/ 目录
  • 不引入后端 API 调用或新的 UI 库
  • 不改变现有功能逻辑和交互流程
  • 不对菜品图片做暗色滤镜处理

2. 用户与场景

用户 / 角色使用场景当前痛点期望结果
门店顾客晚间堂点，弱光环境下使用手机点单浅色背景亮度过高，刺眼不适切换为深色主题，降低屏幕亮度，舒适点餐
门店店员晚间巡台时查看订单和演示控制台浅色界面在暗环境中眩光深色界面减少光线干扰，操作更专注

3. 功能需求

REQ-001P0

黑夜模式切换入口

用户价值：用户需要一个可见、可操作的入口来切换主题。

需求描述：

  • 在 TopBar 工具栏新增图标按钮，位于老人模式按钮和语言切换按钮之间
  • 按钮图标：浅色模式显 Moon，暗色模式显 Sun（lucide-react）
  • 点击切换主题：浅色 → 暗色 / 暗色 → 浅色
  • 提供中/英双语 aria-label
  • 暗色模式下 Sun 图标以 chili-500 色高亮

验收标准：

  • 浅色模式下点击按钮，250ms 内切换为深色主题
  • 暗色模式下点击按钮，250ms 内切换回浅色主题
  • 按钮图标随当前主题正确切换
  • 按钮存在中/英双语 aria-label，随语言切换更新
REQ-002P0

黑夜模式状态管理

需求描述：

  • 新建 src/hooks/useDarkMode.ts，架构参照 useElderlyMode.ts
  • 状态通过 localStorage 持久化，key 为 dark-mode，值为 'true' / 'false'
  • 通过在 document.documentElement 上添加/移除 dark class 驱动 Tailwind dark: 变体
  • localStorage 不可用时降级为内存态，不报错不阻塞
  • 默认关闭（浅色模式）

验收标准：

  • 首次访问默认浅色模式，html 元素无 dark class
  • 切换至暗色后，html 添加 dark class，localStorage 中 dark-mode 为 'true'
  • 刷新页面后主题从 localStorage 恢复，无 FOUC
  • localStorage 不可用时切换功能正常但不持久化，不抛错
REQ-003P0

页面加载防闪烁（FOUC 防护）

需求描述：在 index.html 内联脚本中，React 挂载前读取 localStorage 的 dark-mode 值，若为 'true' 立即在 document.documentElement 添加 dark class。

验收标准：

  • dark-mode 为 'true' 时刷新，首屏直接暗色，无浅色闪烁
  • dark-mode 不存在或为 'false' 时刷新，首屏为浅色
REQ-004P0

Tailwind 暗色配置

需求描述：

  • 在 tailwind.config.js 中设置 darkMode: 'class'
  • 在 theme.extend.colors 中新增暗色专用色阶：
    • dark-bg: #1d1d1d（页面背景）
    • dark-surface: #141414（卡片/容器背景）
    • dark-elevated: #272727（弹窗/提升面背景）
    • dark-border: #3e3e3e（边框）
    • dark-text: #dcdcdc（正文文字）
    • dark-text-secondary: #adadad（次级文字）
    • dark-fill: #303030（填充背景）
REQ-005P0

全视图深色主题适配

需求描述：为所有视图和组件添加 dark: 变体样式，包括 HomeView、WelcomeView、TopBar、MenuView、OrderView、CheckoutView、CartPanel、ServiceSheet、DemoConsole、Button、Dialog、底部导航栏、全局 toast。

暗色色值映射规则：

浅色类名暗色替换说明
bg-rice-50 / bg-rice-100dark:bg-dark-bg页面背景 → #1d1d1d
bg-whitedark:bg-dark-surface卡片背景 → #141414
bg-rice-200dark:bg-dark-elevated次级面板 → #272727
text-charcoal-900dark:text-dark-text主文字 → #dcdcdc
text-charcoal-500 / text-charcoal-700dark:text-dark-text-secondary次级文字 → #adadad
border-charcoal-900/5 / border-charcoal-900/10dark:border-dark-border边框 → #3e3e3e
bg-charcoal-900保持不变深色区域在暗色下仍为深色
text-chili-500保持不变强调色保持品牌红
bg-chili-50dark:bg-chili-500/15浅红背景 → 半透明红
bg-amber-100dark:bg-amber-400/15浅琥珀 → 半透明琥珀
paper-noisedark:paper-noise-dark噪点纹理适配深色

验收标准：

  • 切换至暗色后，所有视图背景为深色，无大面积白色残留
  • 卡片/弹窗/面板背景为 #141414 或 #272727，与页面背景有层次区分
  • 文字在深色背景上对比度 ≥ 4.5:1（WCAG AA）
  • 按钮在暗色模式下保持可辨识性
  • 边框线在暗色模式下可见但不过于突兀
  • 底部导航栏背景为深色，激活态保持 chili-50 半透明
REQ-006P1

i18n 文案支持

需求描述：在 src/i18n.ts 的 common 分组中新增 aria_dark_mode：中文「切换黑夜模式」/ 英文「Toggle dark mode」。

类别要求验收方法

类型描述影响处理方式
