# PRD 文档：黑夜模式（Dark Mode）主题切换

> 为沸点火锅点单 Demo 应用新增黑夜模式主题切换能力，提升夜间及弱光环境下的视觉体验。

---

# 1. 背景与目标

## 1.1 背景

沸点火锅点单 Demo（`hdl-order-demo`）当前为单一浅色主题，所有界面元素使用 rice（米白）/ charcoal（炭灰）/ chili（辣椒红）/ amber（琥珀）色系，颜色类名直接硬编码在 JSX 中。Tailwind CSS 未配置 `darkMode`，组件中无 `dark:` 变体。

餐饮场景中，晚间用餐高峰时段顾客在弱光环境下使用点单界面，浅色背景的高亮度屏幕对眼睛刺激明显。设计系统已提供完整的暗色 token 方案（`tokens.dark.json`），包含暗色背景 `#1d1d1d`、容器背景 `#141414`、文字 `#dcdcdc`、边框 `#3e3e3e` 等完整色阶，可直接作为黑夜模式的色彩基准。

应用已有「老人模式」作为主题切换先例（`useElderlyMode` hook，通过 `localStorage` 持久化 + `html.elderly` class 切换），黑夜模式可采用相同架构实现。

## 1.2 目标

| 目标 | 衡量方式 | 目标值 / 判断标准 |
|------|----------|-------------------|
| 提供黑夜模式切换入口 | 顶栏存在可见的切换按钮 | 用户可在任意视图（home 除外）顶栏找到黑夜模式切换按钮 |
| 全视图深色适配 | 视觉检查所有视图 | home/welcome/menu/order/checkout 五个视图及所有弹窗在暗色下无浅色残留 |
| 偏好持久化 | 刷新页面后保持主题 | 用户切换黑夜模式后刷新页面，主题保持不变 |
| 平滑过渡 | 切换时的视觉体验 | 主题切换有 250ms 平滑过渡，无闪烁 |

## 1.3 不做什么

- 不做跟随系统偏好（`prefers-color-scheme`）的自动模式——本次仅支持用户手动切换。
- 不做主题定制市场或自定义颜色选择。
- 不修改 `server/` 目录（仅健康检查，无业务逻辑）。
- 不引入后端 API 调用或新的 UI 库。
- 不改变现有功能逻辑和交互流程。
- 不对菜品图片做暗色滤镜处理（保持食欲感）。

| 用户 / 角色 | 使用场景 | 当前痛点 | 期望结果 |
|-------------|----------|----------|----------|
| 门店顾客 | 晚间堂点，弱光环境下使用手机点单 | 浅色背景亮度过高，刺眼不适 | 切换为深色主题，降低屏幕亮度，舒适点餐 |
| 门店店员 | 晚间巡台时查看订单和演示控制台 | 浅色界面在暗环境中眩光 | 深色界面减少光线干扰，操作更专注 |

# 3. 功能需求

## REQ-001: 黑夜模式切换入口

- **优先级**：P0
- **用户价值**：用户需要一个可见、可操作的入口来切换主题，满足夜间使用需求。
- **需求描述**：
  - 在 TopBar 工具栏区域新增一个图标按钮，位于老人模式按钮和语言切换按钮之间。
  - 按钮图标使用 lucide-react 的 `Moon`（浅色模式下显示）和 `Sun`（暗色模式下显示）。
  - 点击按钮切换当前主题：浅色 → 暗色 或 暗色 → 浅色。
  - 按钮需提供 `aria-label` 无障碍标签，中/英双语。
  - 暗色模式下按钮图标 `Sun` 以 `chili-500` 色高亮，提示当前处于暗色模式。
- **验收标准**：
  - [ ] 当用户在浅色模式下点击黑夜模式按钮时，界面应在 250ms 内切换为深色主题。
  - [ ] 当用户在暗色模式下点击黑夜模式按钮时，界面应在 250ms 内切换回浅色主题。
  - [ ] 按钮图标随当前主题正确切换（浅色显 Moon，暗色显 Sun）。
  - [ ] 按钮存在中/英双语 aria-label，随语言切换更新。

## REQ-002: 黑夜模式状态管理

- **优先级**：P0
- **用户价值**：用户的主题偏好应被记住，无需每次重新切换。
- **需求描述**：
  - 新建 `src/hooks/useDarkMode.ts` hook，架构参照 `useElderlyMode.ts`。
  - 状态通过 `localStorage` 持久化，key 为 `dark-mode`，值为 `'true'` / `'false'`。
  - 通过在 `document.documentElement` 上添加/移除 `dark` class 来驱动 Tailwind `dark:` 变体。
  - `localStorage` 不可用时降级为内存态，不报错不阻塞。
  - 默认关闭（浅色模式）。
- **验收标准**：
  - [ ] 首次访问应用时，默认为浅色模式，`html` 元素无 `dark` class。
  - [ ] 切换至暗色模式后，`html` 元素添加 `dark` class，`localStorage` 中 `dark-mode` 值为 `'true'`。
  - [ ] 刷新页面后，主题偏好从 `localStorage` 恢复，无主题闪烁（FOUC）。
  - [ ] `localStorage` 不可用时（如隐私模式），切换功能正常工作但不持久化，不抛出错误。

## REQ-003: 页面加载防闪烁（FOUC 防护）

- **优先级**：P0
- **用户价值**：避免页面加载时先闪现浅色主题再切换为暗色，保证视觉一致性。
- **需求描述**：
  - 在 `index.html` 的内联脚本中，React 挂载前读取 `localStorage` 的 `dark-mode` 值。
  - 若为 `'true'`，立即在 `document.documentElement` 上添加 `dark` class。
  - 此操作在 CSS 解析前完成，确保首屏即为正确主题。
- **验收标准**：
  - [ ] 当 `dark-mode` 为 `'true'` 时刷新页面，首屏直接呈现暗色主题，无浅色闪烁。
  - [ ] 当 `dark-mode` 不存在或为 `'false'` 时刷新页面，首屏为浅色主题。

## REQ-004: Tailwind 暗色配置

- **优先级**：P0
- **用户价值**：为所有组件提供 `dark:` 变体支持能力。
- **需求描述**：
  - 在 `tailwind.config.js` 中设置 `darkMode: 'class'`。
  - 在 `theme.extend.colors` 中新增暗色专用色阶，供 `dark:` 变体使用：
    - `dark-bg`: `#1d1d1d`（页面背景）
    - `dark-surface`: `#141414`（卡片/容器背景）
    - `dark-elevated`: `#272727`（弹窗/提升面背景）
    - `dark-border`: `#3e3e3e`（边框）
    - `dark-text`: `#dcdcdc`（正文文字）
    - `dark-text-secondary`: `#adadad`（次级文字）
    - `dark-fill`: `#303030`（填充背景）
- **验收标准**：
  - [ ] `tailwind.config.js` 中 `darkMode` 配置为 `'class'`。
  - [ ] 组件中使用 `dark:` 前缀的类名能正确在 `html.dark` 下生效。

## REQ-005: 全视图深色主题适配

- **优先级**：P0
- **用户价值**：黑夜模式下所有界面元素视觉协调，无浅色残留。
- **需求描述**：
  - 为以下所有视图和组件添加 `dark:` 变体样式：
    - **HomeView**：页面背景、模糊光斑、桌台卡片、按钮、输入区域。
    - **WelcomeView**：背景、卡片、按钮。
    - **TopBar**：顶栏背景、banner、导航按钮、图标按钮。
    - **MenuView**：Hero 区域（保持 charcoal-900 背景）、搜索框、分类标签、菜品卡片、价格文字、规格选择弹窗。
    - **OrderView**：进度面板（保持 charcoal-900 背景）、订单列表卡片、按钮。
    - **CheckoutView**：账单卡片、支付方式卡片、成功页卡片。
    - **CartPanel**：购物车面板、空状态、价格区域。
    - **ServiceSheet / DemoConsole**：弹窗内容、列表项。
    - **Button (CVA)**：所有变体（default/secondary/outline/ghost）的暗色样式。
    - **Dialog**：弹窗背景、标题、内容区。
    - **底部导航栏**：背景、激活态、文字色。
    - **全局 toast 消息**：背景、文字。
  - 暗色色值映射规则（基于 `tokens.dark.json`）：

| 浅色类名 | 暗色替换 | 说明 |
|----------|----------|------|
| `bg-rice-50` / `bg-rice-100` | `dark:bg-dark-bg` | 页面背景 → #1d1d1d |
| `bg-white` | `dark:bg-dark-surface` | 卡片背景 → #141414 |
| `bg-rice-200` | `dark:bg-dark-elevated` | 次级面板 → #272727 |
| `text-charcoal-900` | `dark:dark-text` | 主文字 → #dcdcdc |
| `text-charcoal-500` / `text-charcoal-700` | `dark:dark-text-secondary` | 次级文字 → #adadad |
| `border-charcoal-900/5` / `border-charcoal-900/10` | `dark:dark-border` | 边框 → #3e3e3e |
| `bg-charcoal-900` | 保持不变 | 深色区域在暗色下仍为深色 |
| `text-chili-500` | 保持不变 | 强调色在暗色下保持品牌红 |
| `bg-chili-50` | `dark:bg-chili-500/15` | 浅红背景 → 半透明红 |
| `bg-amber-100` | `dark:bg-amber-400/15` | 浅琥珀 → 半透明琥珀 |
| `paper-noise` | `dark:paper-noise-dark` | 噪点纹理适配深色 |

- **验收标准**：
  - [ ] 切换至暗色模式后，所有视图背景为深色（#1d1d1d），无大面积白色残留。
  - [ ] 卡片、弹窗、面板背景为 #141414 或 #272727，与页面背景有层次区分。
  - [ ] 文字在深色背景上清晰可读，对比度满足 WCAG AA 标准（≥ 4.5:1）。
  - [ ] 按钮在暗色模式下保持可辨识性：default（chili-500 红底白字）、secondary（暗色填充）、outline（暗色边框）、ghost（暗色文字）。
  - [ ] 边框线在暗色模式下可见但不过于突兀（#3e3e3e）。
  - [ ] 底部导航栏背景为深色，激活态保持 chili-50 半透明。

## REQ-006: i18n 文案支持

- **优先级**：P1
- **用户价值**：切换按钮的无障碍标签需随语言切换。
- **需求描述**：
  - 在 `src/i18n.ts` 的 `common` 分组中新增：
    - `aria_dark_mode`: 中文「切换黑夜模式」/ 英文「Toggle dark mode」
- **验收标准**：
  - [ ] 中文环境下按钮 aria-label 为「切换黑夜模式」。
  - [ ] 英文环境下按钮 aria-label 为「Toggle dark mode」。

# 4. 产品规则

## 4.1 页面与交互

| 位置 / 入口 | 用户操作 | 系统反馈 | 备注 |
|-------------|----------|----------|------|
| TopBar 黑夜模式按钮 | 点击按钮 | 全局主题在浅色/暗色间切换，250ms 过渡动画 | 按钮位于老人模式按钮与语言切换按钮之间 |
| 页面刷新 | 无 | 从 localStorage 恢复主题偏好，首屏无闪烁 | index.html 内联脚本预置 dark class |

## 4.2 字段与校验

| 字段 | 类型 | 是否必填 | 默认值 | 校验规则 | 展示 / 使用位置 |
|------|------|----------|--------|----------|-----------------|
| dark-mode (localStorage) | string | 否 | 'false' | 'true' / 'false' | useDarkMode hook |

## 4.3 状态与流转

| 操作 | 前置状态 | 目标状态 | 用户可见反馈 |
|------|----------|----------|--------------|
| 点击黑夜模式按钮 | light | dark | 界面切换为深色主题，按钮图标变为 Sun |
| 点击黑夜模式按钮 | dark | light | 界面切换为浅色主题，按钮图标变为 Moon |
| 页面刷新 | dark | dark | 首屏直接呈现暗色主题，无闪烁 |

## 4.4 接口或数据契约

不涉及对外接口、导入导出、通知、数据格式变化。

| 契约对象 | 变化内容 | 是否兼容 | 关联需求 |
|----------|----------|----------|----------|
| 无 | 无 | 是 | 无 |

# 5. 约束与风险

## 5.1 非功能要求

| 类别 | 要求 | 验收方法 |
|------|------|----------|
| 兼容性 | 黑夜模式与老人模式可同时启用，互不冲突 | 同时开启两种模式，视觉检查 |
| 性能 | 主题切换不引起页面重排/重绘性能问题 | 切换时无明显卡顿 |
| 可访问性 | 暗色模式下文字对比度 ≥ 4.5:1（WCAG AA） | 使用对比度检查工具验证 |
| 可用性 | localStorage 不可用时功能降级但不报错 | 隐私模式下测试切换功能 |
| 一致性 | 暗色色值来源于设计系统 tokens.dark.json | 与设计系统色值对照 |

## 5.2 风险与待确认

| 类型 | 描述 | 影响 | 处理方式 |
|------|------|------|----------|
| 风险 | 组件数量多，dark: 变体覆盖遗漏可能导致局部浅色残留 | 视觉不一致 | 逐视图检查 + E2E 截图对比 |
| 风险 | 老人模式 + 黑夜模式叠加时字号放大可能影响布局 | 布局溢出 | 两种模式同时启用时检查关键视图 |
| 待确认 | 是否需要跟随系统偏好 prefers-color-scheme | 未来范围 | 本次不做，记录为后续迭代项 |
